# 📚 学习助手 Pro

面向学生的个人学习管理智能体：课程资料归档、DDL 提醒、资料检索、定制复习方案，全部数据只保存在自己电脑上。

## ✨ 功能总览

| 模块 | 功能 |
|---|---|
| DDL 管理 | 手动录入 / 粘贴文本一键提取（支持"下周三下午两点""8月20日23:00"等说法）/ 智能体自然语言添加 |
| 资料管理 | 文件上传入库、文件名自动识别课程和标签、按关键词/课程/标签检索（FTS5 全文搜索）、下载 |
| 复习计划 | 按「学习画像」定制节奏生成（提前天数/频率/薄弱科目加权），可勾选完成 |
| 提醒 | 首页醒目标注 + iCal 导出（带"提前1天/提前3小时"闹钟，导入手机日历）+ 智能体每日主动通知 |
| 智能体 | 对话式问答与操作（查 DDL/资料/复习、增删改任务、生成复习计划），支持智谱（免费）/ DeepSeek |
| 导出 | iCal / CSV（Excel 不乱码）/ Markdown 三种格式 |
| 爬虫 | 学习通全自动同步（手机扫码登录，不用密码，Playwright 抓取作业/考试 DDL）+ 半自动粘贴兜底；教务系统同步（南理工：课表 / 考试安排，队友功能） |
| 安全 | 账号密码与 API Key 加密存储、启动自动备份（保留 10 份）、WAL 事务保护（强杀进程不丢数据） |

## 🚀 快速开始

**方式一（推荐，无需安装 Python）**：双击 `dist/StudyHelper-Setup.exe` 安装程序 →
选择安装位置 → 安装 → 桌面自动出现「学习助手Pro」图标 → 双击即可使用（无黑色窗口，浏览器自动打开）。
关闭应用：双击安装目录里的 `停止学习助手.bat`。

**方式二（源码运行）**：
1. 安装 [Python 3.12](https://www.python.org/downloads/)（安装时勾选 **Add python.exe to PATH**）
2. **双击桌面图标「学习助手Pro」**（或项目里的 `启动学习助手.vbs`）——静默启动，无黑色窗口，浏览器自动打开
3. 要关闭时，双击项目里的 **`停止学习助手.bat`**

> 首次启动会自动创建虚拟环境、安装依赖（约 1 分钟，之后秒开）。
> 想查看运行日志/控制台输出：直接双击 `run.bat`（带黑色窗口版本）。

## 📦 打包发布（做成安装程序）

想把这个应用发给同学/拷到其他电脑？运行一次 `build_exe.bat` 即可（需要本机装好依赖的 venv）：

| 产物 | 说明 |
|---|---|
| `dist/StudyHelper/` | 主程序文件夹（内含 StudyHelper.exe，整个文件夹拷走也能用） |
| `dist/StudyHelper-Setup.exe` | **安装器**：双击 → 选安装位置 → 自动创建桌面快捷方式 |

安装器特性：
- 数据存在安装目录的 `data/` 下（数据库/备份/上传文件），**换电脑拷走整个安装目录 = 完整搬家**
- 覆盖更新会**保留原有数据**（重装不丢数据）
- 程序正在运行时重装，会提示先关闭应用
- 卸载 = 删掉安装目录 + 桌面快捷方式

## 🎬 演示脚本（答辩用，约 5 分钟）

1. **首次进入**：完成「学习画像」问卷（每天 2 小时、提前 14 天、隔天复习、薄弱科目填"高数"）
2. **资料入库**：上传 `高等数学-第3章-作业.pdf` → 自动识别课程"高等数学"+标签"作业"→ 入库
3. **检索**：搜索页搜"第三章"→ 关键词高亮命中（全文索引）
4. **DDL 提取**：DDL 页粘贴「高数作业截止于8月20日23:00，请大家按时提交」→ 一键提取 → 课程自动识别 → 确认入库
5. **智能体**（演示前先在设置页配好 API Key）：
   - 「这周有什么考试？」→ 智能体查库回答
   - 「帮我记一下：下周三下午两点考大物」→ 自动换算日期入库
   - 「删除大物考试那条」→ 智能体先确认再删
6. **复习方案**：为考试生成复习清单 → 展示画像定制效果（次数/节奏与默认不同）→ 勾选完成
7. **提醒**：导出 iCal → 导入手机日历 → 展示事件带"提前1天""提前3小时"两个闹钟
8. **导出**：复习清单 Markdown（含画像说明）/ CSV（Excel 打开不乱码）
9. **安全**：设置页展示备份文件列表 → 点「立即备份」→ data/backups/ 出现新文件；数据库文件里 API Key 是密文
10. **稳定性**：任务管理器强杀进程 → 重新启动 → 数据完好、备份自动生成

## ❓ 常见问题

- **端口 5000 被占用**：改 `config.py` 里的 `PORT`，或关掉旧窗口再启动
- **控制台中文乱码**：`run.bat` 已内置 `chcp 65001`，一般不会出现
- **pip 安装失败（网络问题）**：换清华镜像：`python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`
- **智能体不回答**：设置页 → 测试连接（检查 Key/模型名/网络）
- **学习通同步提示"无法启动浏览器"**：源码版需先装浏览器内核（一次性）：
  `venv\Scripts\python.exe -m playwright install chromium`；打包版已内置，不会出现
- **扫码后没反应 / 提示登录过期**：登录态约 7 天有效，在设置页重新扫码即可；也可以改用「半自动粘贴」模式
- **爬虫同步失败**：属正常（学习通页面可能改版），改用「半自动粘贴」模式；不影响其他任何功能
- **教务系统提示"需要校园网/VPN"**：校外访问受限，用「半自动同步」粘贴考试安排文字即可
- **改了代码不生效**：必须重启应用（关窗口 → 重新双击 run.bat）

## 🗂️ 数据位置

> 打包版（exe）的数据在**安装目录**的 data/ 下；源码版在**项目目录**的 data/ 下。

| 内容 | 位置 |
|---|---|
| 数据库 | `data/study.db`（WAL 模式，事务保护） |
| 备份 | `data/backups/`（自动保留最近 10 份） |
| 上传的资料 | `data/uploads/` |
| 加密密钥 | `data/key.key`（丢了无法解密已存密码，请勿删除） |

## ⚠️ 安全边界说明

- 账号密码、API Key 均用密钥文件加密后存储：数据库文件被拷贝也无法直接读出明文
- 防御目标是对"数据库文件泄露"；不宣称能防本机木马（那是更高成本方案的范畴）
- 智能体对话会把你的消息发送给所选大模型服务商（智谱/DeepSeek）做理解
